# Portfólio profissional — Jayme Neto

Site estático responsivo com HTML, CSS e JavaScript, desenvolvido para apresentação profissional e publicação via GitHub Pages.

O portfólio reúne projetos técnicos, trajetória profissional, competências e currículo para download. As galerias de audiovisual e design serão preenchidas em futuras atualizações.

## Executar localmente

Abra `index.html` no navegador, ou sirva os arquivos com um servidor HTTP estático.

## Estrutura

- `index.html`: conteúdo e estrutura.
- `style.css`: identidade visual e responsividade.
- `script.js`: navegação móvel e filtros de projetos.
- `jayme.jpg`: fotografia pessoal.
- `curriculo.pdf`: currículo profissional.
